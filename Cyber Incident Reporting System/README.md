# 🚨 Cyber Incident Reporting System

A frontend web app to report, store, review, and delete simulated cybersecurity incidents.

## 🔹 Features
- Incident reporting form
- Incident type and severity classification
- Incident description storage
- Date and time for each report
- Incident history table
- Delete reported incidents
- LocalStorage persistence
- Responsive dark cyber-themed UI

## 🛠 Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🎯 Use Case
Designed as a SOC / cybersecurity portfolio simulation for learning frontend incident-management workflows.

## ⚠ Note
This is a browser-based educational demo. It is not connected to a real SOC backend, ticketing system, or security database.
