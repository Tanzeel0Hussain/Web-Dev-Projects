# 🌤️ Weather UI Web App (API-LESS)

A clean and responsive **Weather UI Web Application** built using HTML, CSS, and JavaScript.

This project intentionally does **not** use an external weather API. It demonstrates UI design and JavaScript DOM manipulation using simulated weather data.

## 🚀 Features
- Enter any city name
- Random weather simulation
- Dynamic temperature, condition, humidity, and wind display
- Responsive frontend UI
- No API key required

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📂 Project Structure

```text
Weather App/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 📌 How It Works
1. Enter a city name.
2. JavaScript selects one of the built-in sample weather states.
3. The UI updates instantly.

## ⚠ Note
The displayed weather is simulated and is **not real weather data**.
